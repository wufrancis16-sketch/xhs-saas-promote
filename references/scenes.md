## 电子账本场景库（5大核心触发场景）

### 场景1：税局突然通知查账

**痛点描述**：
- 税局要求提供指定年份的账务资料
- 需准备凭证、总账、明细账、科目余额表、账簿等
- 旧电脑/软件打不开、数据找不到
- 代账公司几十本账可能耗时一整天

**文案方向**：
```
开头：我干了十几年会计，最怕的就是税局突然来电话...
税局要查账，需要准备好几年的凭证账本，
旧电脑打不开了，急得团团转...
```

---

### 场景2：客户突然索要历史账

**痛点描述**：
- 代账会计高频场景
- 客户要求发送过往年份账务资料
- 账务资料可能存于旧电脑、旧软件、旧U盘
- 查找困难，甚至找不到

**文案方向**：
```
开头：做代账这么多年，客户临时要账本这事...
客户突然要去年的账，我翻遍了整个办公室，
U盘找不到，旧电脑开不了机，当场崩溃...
```

---

### 场景3：公司换会计/离职交接

**痛点描述**：
- 老板要求交接过往所有年份账务
- 需整理大量凭证、账本
- 因软件版本不同导致资料无法打开
- 交接流程繁琐，交接双方都头疼

**文案方向**：
```
开头：上次公司换会计，我们财务室炸锅了...
老板说要交接收了5年的账，
纸质凭证堆成山，软件版本太老打不开，
跟新来的会计battle了半个月...
```

---

### 场景4：企业审计/融资/投资

**痛点描述**：
- 审计师要求提供总账、明细账、科目余额表、辅助账等账簿资料
- 资料准备效率极低
- 影响审计/融资进度

**文案方向**：
```
开头：去年公司要做融资，审计机构要一堆账...
会计师要总账明细账，我整理了三天三夜，
来回跑档案室，最后还被说资料不全...
```

---

### 场景5：税务风险自查

**痛点描述**：
- 税局指出指定时间的账务数据存在问题
- 需要快速查账核实
- 人工逐本翻找凭证，工作量大

**文案方向**：
```
开头：做会计的都知道，税局让你自查的时候最慌...
要核对某一年的成本数据，
几百本凭证一本本翻，眼睛都快瞎了...
```

## 电子账本核心价值（多样化表达）

1. **税局要** → 直接给电子账本，省打印费
2. **客户要** → 直接给电子账本，不用打印了
3. **交接用** → 一个文件完成全部交接，不用纸质账本
4. **审计用** → 全套规范账簿随时导出
5. **税局查** → 精准搜索科目，历史数据永久可查
6. **附件全** → 电子账本把发票附件一起带过来，不仅仅是凭证

## 进销存场景库

### 手机开单场景

**痛点描述**：
- 在仓库/外面跑业务，无法用电脑开单
- 客户电话催单，价格记不住
- 开单后库存数据不同步
- 老板想查库存，业务员在外面无法回复

**文案方向**：
```
开头：在仓库管库存，最烦的就是客户打电话来要单...
我在卸货，客户来电话要报价，
手上有货但不知道卖多少，还得跑回办公室查...
```

---

### 库存管理场景

**痛点描述**：
- 库存数据总是对不上
- 不知道哪些货缺了
- 盘点全靠人工，耗时耗力
- 批次/保质期管理混乱

**文案方向**：
```
开头：做批发的，最头疼的就是库存对不上...
每次盘点都发现这个少那个多，
保质期快到了也不知道，等卖出去才发现过期了...
```

---

### 客户对账场景

**痛点描述**：
- 客户多，价格体系复杂
- 对账全靠手工Excel
- 业务员开的单，老板不知道收没收钱
- 应收款一堆，回款难追

**文案方向**：
```
开头：管销售这么多年，客户一对账就头大...
几十个客户价格都不一样，
上个月给谁优惠了多少根本记不清，
对账的时候吵来吵去...
```

## 财务软件/AI做账场景库

### 单机版升级云端场景（高情绪共鸣）

**痛点描述**：
- 电脑突然坏了，一年的账数据全没了，手动备份早就忘了
- 只能在公司那台电脑做账，出差/在家完全没法操作
- 没有手机端，老板在外面想看报表，只能让会计拍照发过去
- 每年年结操作繁琐，要新建年度账，步骤多容易出错
- 跨年查账要退出重进，换个年度账找半天
- 电脑升级Win10/Win11，发现软件打不开了
- 软件用了5年，官方停止维护，出问题找不到人
- 做凭证还要手动填现金流量表，繁琐又容易遗漏

**文案方向**：
```
开头：用了5年单机版财务软件，有天电脑突然坏了，一年的账全没了…
手动备份早就忘了，数据说没就没，当时真的崩溃了…

或者：
以前只能在公司那台电脑做账，有次出差月底要结账，
急得我只能远程让同事帮忙操作，太不方便了…
```

---

### 手工做账累场景

**痛点描述**：

- 银行流水一笔笔录，眼睛都花了
- 月底结账，对账对不平
- 小白会计不会做账，不敢下手

**文案方向**：
```
开头：每个月最怕的就是月底结账那几天...
几百张发票要录凭证，银行流水要对，
手工录入录到手抽筋，对账还对不平...
```

---

### 报税繁琐场景

**痛点描述**：
- 各个税局网站来回登录
- 税表一张张填，容易填错
- 季度申报忙到飞起
- 怕漏报、怕填错被罚款

**文案方向**：
```
开头：会计最烦的不是做账，是报税...
增值税、所得税、附加税...
每个税局都要登录，密码都记不住，
填表填到眼花，还怕一个不小心填错了...
```

**痛点描述**：

- 老会计离职，留下烂摊子
- 凭证乱，账目乱，不知道怎么理

```

```

**痛点描述**：

## AI智能体场景库（AI进入ERP/财务系统）

### AI智能体替代手工重复场景

**痛点描述**：
- 每天重复做同样的事：录发票、做凭证、对账、结账，像流水线工人
- 明明知道这些事AI能做，但不知道怎么用起来
- 担心AI做错了没人发现，出了事要自己背锅
- 会计应该做分析和决策，但现在80%时间都在做重复录入

**文案方向**：
```
开头：做了10年会计，每天还是在录凭证、对账、结账，感觉自己像个打字员...
明明AI都能做了，为什么我还在手动录入...
后来试了下AI智能体做账，真的惊到了...
```

---

**痛点描述**：
- 手里管几十上百家客户，哪家发票没认证、哪家申报逾期根本盯不过来
- 被税局通知某客户有风险，自己事先完全不知道
- 月底批量报税压力大，稍不注意就漏报
- 传统做法是靠Excel表格人工跟踪，效率低还容易遗漏

**文案方向**：
```
开头：做代账最怕的就是某天税局打电话来说客户有问题...
几十家客户，哪家发票没认证、哪家申报逾期，
根本盯不过来，出了问题第一个背锅的就是我们...
后来用了AI智能体风控，它自动帮我盯着...
```

### AI智能体对话式操作场景

**痛点描述**：
- 财务软件功能越来越多，菜单层级深，找功能要翻半天
- 新来的会计不会用软件，培训周期长
- 想做一个操作，不知道在哪个菜单里
- 复杂操作步骤多，容易点错

**文案方向**：
```

```

**痛点描述**：


# 场景选择策略

## 生成内容时选择场景的原则

1. **根据产品功能选择匹配场景**
   - 电子账本 → 选5大核心触发场景之一
   - AI做账 → 选手工做账累/报税繁琐场景
   - AI智能体 → 选"AI智能体"场景库中的4个场景之一（替代手工/主动风控/对话操作/经营洞察）
   - 进销存 → 选手机开单/库存管理/对账场景
   - 升级单机版 → 选"单机版升级云端场景"（高情绪共鸣，转化率高）

2. **同一产品每次选不同场景**
   - 第一次写电子账本：用"税局查账"场景
   - 第二次写电子账本：换"客户索要历史账"场景
   - 避免重复，让内容多样化

3. **场景+功能灵活组合**
   - 场景是痛点，功能是解决方案
   - 同一个功能可以匹配多个不同场景
   - 根据当天灵感自由组合

4. **优先选择有共鸣的通用场景**
   - "税局查账"、"客户要账"是会计共性痛点
   - 比行业专属场景更容易引发共鸣
   - 新账号优先用通用场景打共鸣
