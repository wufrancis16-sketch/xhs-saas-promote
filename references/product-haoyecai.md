## 一、产品定位与核心功能

### 1.1 产品定位
用友好业财是用友旗下成员企业**畅捷通**（港股代码：1588.HK）推出的**面向成长型中小微企业的业财税票一体化SaaS管理平台**。官方定位：**"创新企业数智经营平台"**。

核心Slogan演进：**"从管控到赋能，为您创造商业价值"** → **"从管控到AI赋能，为您创造商业价值"** → **"驾驭AI 畅行未来 懂业务的数智新员工"**。

### 1.2 核心功能模块（12大板块）

| 功能板块 | 详细能力 |
|---------|---------|
| **① 进销存管理** | 采购管理（采购订单/进货单/发票/费用分摊/损耗/暂估/冲抵）、销售管理（销售订单/出库单/发票/价格策略/智能批量改价/毛利分析/损耗/冲抵）、库存管理（盘点/调拨/组装拆卸/手机电脑随时查库存/自动生成收发存汇总表/库存成本实时核算） |
| **② 往来资金管理** | 收款/付款/预收/预付管理、费用支出/其他收入管理、日记账/现金银行管理、客户/供应商智能对账 |
| **③ 总账/财务管理** | 业务单据智能生成凭证、自动生成三大报表、余额表/序时账/多栏辅助账、期末结转/归档管理、智能识别银行对账单、往来账智能核销 |
| **④ 项目合同管理** | 项目列表/看板/进度管理、收入/支出合同/收入确认单、项目预算管理（变更/执行跟踪）、项目人料机费核算一体化 |
| **⑤ 发票与税务管理** | 业务开票/查验取票/进销稽核、发票测算/电子归档、税务风险检测/税负波动分析、一键报税 |
| **⑥ 营销管理** | 优惠券促销/价格策略/历史价格跟踪、客户分层经营/互动联络/精准营销、商品分析/异常商品预警、6种销售提成方式、车访销管理 |
| **⑦ 智慧门店/零售** | 零售POS开单收银、会员电子卡管理（会员价/积分/储值/等级）、多种促销方式、聚合支付、对接电子秤/小票打印机 |
| **⑧ 微商城/线上渠道** | 微信小程序商城+公众号商城、直播卖货/拼团/裂变/限时秒杀、快递发货/同城配送/门店自提、线上线下统一商品/库存/价格 |
| **⑨ 生产管理（加购）** | 生产加工单/BOM物料清单、领料/入库/委外加工、MRP计划运算/齐套分析、移动端生产工作台 |
| **⑩ 智能仓储WMS** | 多人同时移动盘点、拣货任务/路线规划、拣货/分货/验货/装箱、人员计件绩效 |
| **⑪ 智搭平台（低零代码）** | 可视化配置自定义业务流程、自定义数据表单和分析报表、SQL报表设计器、自定义单据模板 |
| **⑫ AI数智员工（3.0核心）** | 营销助理机器人、审批机器人、流程机器人、往来结算机器人、发票机器人、财务机器人、税务机器人、CC智能体AI录入、AI问数、数智参谋 |

## 四、产品亮点与差异化优势

### 4.1 六大核心差异化优势

**① 业财税票一体化——"业务发生即财务记录"**
- 业务数据在产生瞬间自动触发财务凭证生成
- 打通"合同-发票-资金-物流"四流一致性稽核
- 告别进销存与财务两套软件割裂

**② AI数智员工——7×24小时自动化值守**
- 50+智能体覆盖营销/审批/流程/结算/发票/财务/税务各环节
- CC智能体AI录入：语音/文字输入自动识别录入单据
- AI问数：自然语言查询经营数据
- 数智参谋：自动生成200+维度经营看板

**③ 项目管理深度——项目型企业首选**
- 项目预算→进度→成本→结算回款全链路管控
- 竞品（金蝶云星辰）缺乏原生项目管理方案

**④ 全渠道/新营销融合**
- 线上+线下统一管理
- 优惠券/拼团/裂变/秒杀/直播卖货
- 客户分层经营、精准营销

**⑤ 智搭平台——低零代码定制**
- "标准化SaaS + 千人千面定制"的融合

**⑥ 生态集成**
- 与钉钉、企业微信、飞书深度集成
- 银企云联、API接口开放
- 企微客情助手：边聊天边开单/对账/收款
