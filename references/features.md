# 功能点选择策略

## 每次生成时的选择原则

1. **先确定首段痛点** → 再选择能解决这个痛点的功能点
2. **选择2-3个功能点即可** → 不要把所有功能都列出来
3. **每次选择不同的组合** → 避免同质化
4. **功能点要有逻辑关联** → 解决同一个痛点的功能放一起

## 功能点组合示例

**示例1：手工做账累**
- 痛点：发票多，手工录入做凭证做到崩溃
- 功能点组合A：发票管理（一键取票）+ 智能生成凭证
- 功能点组合B：银行流水日记账 + 批量做账
- 功能点组合C：AI做账（说出业务自动生成）

**示例2：库存和账对不上**
- 痛点：仓库说卖了，财务说没收到款
- 功能点组合A：打通进销存 + 实时库存
- 功能点组合B：库存核算 + 账实一致

**示例3：项目成本算不清**
- 痛点：老板问项目赚了没，自己算不出来
- 功能点组合A：成本归集 + 利润实时
- 功能点组合B：分项目核算 + 成本预警

**示例4：AI智能体做账（新方向）**
- 痛点：每天重复录凭证、对账，感觉像打字员
- 功能点组合A：AI Agent 自主做账 + 人机协同模式
- 功能点组合B：对话式操作 + AI Agent 智能风控
- 功能点组合C：AI Agent 自动报税 + AI Agent 经营洞察

**示例5：AI智能体风控（新方向）**
- 痛点：手里几十家客户，哪家有问题根本盯不过来
- 功能点组合A：AI Agent 智能风控 + AI Agent 客户管理
- 功能点组合B：合规风控看板 + 风险提前预警

# 避免同质化的技巧

1. **同一个痛点准备3套功能组合** → 轮换使用
2. **同一产品准备3个不同痛点** → 交替发布
3. **同款产品每周选不同角度** → 避免连续相似
4. **功能点描述可以换说法** → 不要每次都一样
