# 小红书文案写作框架

## 核心：三段式文案结构

### 第一段：痛点场景（50-80字）

**目的**：引发共鸣，让目标用户代入

**写作要点**：
- 以第一人称"我"讲述
- 描述真实工作场景中的困难
- 选取引发目标用户共鸣的痛点
- 语气口语化、生活化
- 不要写成说明书风格

**常见痛点场景**：
- 代账会计：客户要账本找不到、对账对到头秃、换会计交接麻烦
- 会计：不会做账/凭证做不平、税局查账手忙脚乱
- 老板：库存对不上、应收账款收不回、报表看不懂
- 业务员：开单慢、客户价格记不住、外勤效率低
- 单机版用户：电脑坏了数据丢失、只能在公司做账、没有手机端、跨年查账麻烦
- AI智能体用户：重复录入太累、风控盯不过来、软件操作复杂、经营数据分析难

**示例**：
```
我是做酒厂销售的会计，每天跟库存打交道，库存数据总是对不上，
每次盘点都头大，客户要查历史订单，我得翻半天Excel...
```

---

### 第二段：解决方案（100-200字）

**目的**：展示软件如何解决问题

**写作要点**：
- 引入软件/工具
- 描述使用后的改善效果
- 选择2-3个核心功能点展开，不要全部列举
- **✅ 每个功能点前加 ✅ 符号，并单独分段**
- 适当添加emoji增强可读性
- 语气有惊喜感、真实体验感

**核心功能展示技巧**：
- 不要列举所有功能
- 挑2-3个真正能解决第一段痛点的功能
- 用场景化的语言描述，不要写成功能清单
- 突出"用了之后的变化"

**电子账本展示角度**：
1. 税局要直接给电子账本 → 省打印费
2. 客户要不用打印了 → 直接给电子账本省钱
3. 交接给别的会计 → 不用交接纸质账本
4. 审计时 → 非常便利

**AI做账展示角度**：
1. 5分钟200张凭证 → 效率提升
2. 发票、银行流水自动识别 → 省去手工录入
3. 智能办税一键申报 → 不用跑税局

**格式示例**：
```
后来换了云端财务软件，这些问题全解决了！

✅ AI做账太香了，5分钟200张凭证，发票扫一扫自动识别，
会计科目自动匹配，再也不用手动录凭证了

✅ 一键报税太省事，增值税、所得税自动生成报表，
直接在手机上申报，再也不用跑税局了

✅ 电子账本一键导出，客户要什么格式直接给，
交接的时候特别方便，连发票附件都一起带过来了
```

---

### 第三段：推荐引导（30-50字）

**目的**：引导用户尝试/互动

**写作要点**：
- 以过来人身份真诚推荐
- 可以留个小钩子引导互动
- 语气亲切、不强迫
- 可以用"同行朋友们"、"会计同仁们"等称呼

**示例**：
```
同行朋友们真的可以试试，说不定也能帮到你们！
你们有没有遇到过类似的问题？评论区聊聊~
```

## 不同产品的文案变体

**适用场景**：初创公司、小企业会计、职业会计

**标题方向**：
- 价格敏感："新公司用财务软件真别挑太贵的！够用就行！"

**适用场景**：所有使用AI智能体功能的会计/代账/企业管理者

**标题方向**：

## 内容创作注意事项

1. **字数控制**：总字数不超过500字
2. **emoji使用**：在功能点位置适当添加，增加可读性
3. **段落分隔**：内容多时拆成2段，中间空行
4. **第一人称**：全程以"我"的视角叙述
5. **功能取舍**：不要把所有功能都列出来
6. **口语化表达**：就当在跟朋友聊天
7. **避免硬广感**：不要写成产品说明书
8. **升级角度情绪要点**：写单机版→云端升级时，重点突出"数据安全感"和"自由感"，用真实场景（电脑坏了、出差做不了账）引发共鸣
